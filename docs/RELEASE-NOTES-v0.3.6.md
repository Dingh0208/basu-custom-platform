# ClientAtlas v0.3.6

## 更新内容

- 恢复“从微信库提取”：可选择账号、会话、日期和消息类型，与文件及邮箱邮件加入同一待导入清单统一提交。单次最多 5,000 条，本机累计最多 100,000 条。
- 微信库提取组件改为首次使用时单独下载。点击入口会提示安装并显示下载进度；文件通过 SHA-256 校验后保存在用户数据目录，后续升级继续复用。旧版内置组件在覆盖安装前迁移，无需再次下载。
- 微信组件从主安装包移出；应用自己的 Sidecar、FFmpeg 和其他资源保持在 `resources` 分类目录。Electron 运行必需的 DLL/PAK 仍位于程序根目录。
- 延续 0.3.5 尚未发布的更新：品牌及图标改为 ClientAtlas；资料支持多选、批量关联改派和批量删除；导入时不再按材料自动创建或关联客户/项目；历史澄清单可追加材料，Word/PDF 导出带原文依据。

## 安装与隐私

- 微信组件需要首次使用时联网下载；已安装组件以及已导入聊天数据保留在本机。
- Release 仅包含程序、组件与更新元数据，不包含本机数据库、聊天记录、邮箱授权码或 `.env`。
- 安装包：`ClientAtlas-Setup-0.3.6.exe`（离线主程序）、`ClientAtlas-Web-Setup-0.3.6.exe`（在线安装器）。
- Sidecar API revision：29。
