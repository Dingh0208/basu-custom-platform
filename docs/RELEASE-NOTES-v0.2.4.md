# ClientHub v0.2.4 更新内容

发布日期：2026-10-30

## 修复

- **修复设置页「测试连接」「拉取模型」报错 `Expecting value: line 1 column 1 (char 0)`**
  - 修复 Sidecar 请求 `/models` 时响应体在 `with` 块退出后被提前关闭、导致读取为空的问题；
  - `/chat/completions` 与 `/models` 增加空响应、非 JSON、HTTP 错误的结构化提示，不再直接把 `JSONDecodeError` 抛给用户；
  - 设置页请求超时由默认 2 秒放宽到 60 秒，避免网络较慢时误报连接失败；
  - 模型接口兼容 `data` / `models` / 顶层数组等常见返回结构。

## 新增与优化

- 首页工作台上线：客户 / 项目 / 需求 / 待归档统计、最近导入、项目阶段分布、最新需求与快捷入口。
- 设置页精简：保留大模型配置、数据与版本信息、检查更新，移除「通用设置」。
- 设置页布局优化：改为 `1.35fr / 0.65fr` 自适应布局，左右卡片等高，减少右侧空白。

## 安装

- 下载 `ClientHub-Setup-0.2.4.exe`，安装时可选择安装路径。
- 覆盖安装会保留本机的客户记录、导入文件与大模型配置；应用数据不会提交到仓库。
