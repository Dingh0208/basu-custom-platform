# ClientHub v0.3.1

发布日期：2026-11-03

## AI 分析速度与完整性

- 优化资料摘要、聊天分析和需求澄清的文本请求。兼容的 Qwen3 混合模型关闭思考模式，减少等待；保留用户配置的模型。
- 文本结构化分析不再设置输出 token 预算，纠正重试也不限制输出预算。长资料摘要读取完整正文，避免遗漏中间内容。
- 优化澄清提示词，减少模型重复生成可由本地补齐的元数据，保留问题、理由和原文证据，不限制问题数量。
- 使用虚构资料对 `qwen3.8-flash` 实测：摘要由约 19.2 秒降至 4.2 秒，完整澄清约 25.7 秒。实际耗时取决于资料长度、模型及网络，不保证所有分析在 10 秒内完成。

## JSON 错误与分析进度

- 修复模型回复含 Markdown 围栏、说明文字或文本块时的解析问题；检测空正文和长度截断，避免把截断 JSON 内部的局部对象误当完整结果。
- 格式或结构错误时自动纠正一次，仍失败则保留工作单、已有结果、回答及错误原因；重试可继续未完成批次。认证失败不自动重复调用。
- 分析进度显示当前批次、等待模型和自动纠正阶段；摘要生成期间显示“正在生成…”。

## 聊天、微信与界面修复

- 同一微信会话增量合并，重复消息自动跳过，并显示本次新增数和累计数；AI 分析按设置开关执行。
- 长聊天分块分析并保存成功批次检查点，失败重试复用已完成结果，避免只分析末尾内容。
- 微信引擎使用可写的专用解包目录并提供备用目录；限制启动重试、保留诊断和手动重试入口，修复打包组件完整性级别导致的启动故障。
- 修复文档原文和校正输入框挤在窄列的问题，改善换行与阅读宽度。
- 修复更新下载、待安装状态被迟到的“无更新”事件覆盖的问题；侧栏版本号与应用包版本保持一致。
- Windows 后端独占监听端口，并在初始化数据和恢复任务前检查端口冲突，避免桌面版与开发版同时监听、界面访问到旧后端。

## 验证与升级

- 107 项 Python 回归测试、TypeScript/Vite 生产构建通过；包含 JSON 恢复、长资料完整性、聊天增量、引擎故障恢复及 Windows 端口冲突回归。
- 已完成一次用户自行发起的真实澄清：约 36 秒生成并保存完整结果，无 JSON 错误；此为单次观测。
- Windows 安装包通过 GitHub Actions 构建，包含 Sidecar API20；发布资产包括 NSIS 安装包、差分更新文件和 `latest.yml`，不包含开发环境密钥文件。
- 安装前请完全退出旧版 ClientHub。使用开发 Web 服务时，请先退出桌面版，避免端口冲突；可通过安装包升级或使用应用内更新入口。
- 本版本尚未完成人工全新 Windows 10/11 安装、覆盖升级及自动更新下载后重启安装的完整验收。
