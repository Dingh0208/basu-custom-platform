# Sprint 1 产品原型说明

## 1. 这版原型解决什么

对应 PRD 的 Sprint 1 第一条主链路：

> 导入录音 → 音频转码/切片 → ASR 转写 → 说话人区分 → 结构化摘要 → 人工校对/重新生成

这版原型覆盖两个核心页面：

1. **导入中心**：拖拽、批量选择、粘贴文本/截图、文件类型识别、SHA-256 去重、自动识别客户、待归档提示。
2. **转写与摘要**：音频播放器、时间戳、说话人角色、点击句子定位、固定七字段摘要、空字段“未提及”、原文引用、编辑与重新生成。

## 4. 页面说明

### 4.1 导入中心

对应 PRD 6.1 多来源导入中心。

- 顶部 KPI：今日已导入 / 处理中 / 待归档 / 最近一条录音；
- 大拖拽区：支持音频、视频、PDF、Word、Excel、PPT、图片、压缩包、聊天记录；
- 三个入口：选择文件、粘贴文本、粘贴截图；
- 最近导入表：文件名、类型、大小、识别客户、状态、时间；
- 右侧设置：自动识别客户、默认项目、AI 模式（阿里云百炼/Mock）、识别规则、导入后自动处理；
- 底部提示：失败项自动进入待归档，不会丢失。

### 4.2 转写与摘要

对应 PRD 6.3 通话转写与结构化摘要。

- 左侧：文件信息、处理进度（上传/转码/转写/摘要）、摘要依据数量；
- 中间：音频播放器 + 波形 + 时间 + 倍速；转写稿按时间排序，区分“客户/我”，支持搜索“预算”并高亮；点击句子可跳转音频时间点；
- 右侧：AI 摘要固定七字段：一句话结论、客户需求与痛点、预算与报价、时间与优先级、决策人与角色、异议与风险、下一步动作；空字段显示“未提及”；
- 每个字段带“原文引用”图标，可跳转；
- 底部：重新生成、保存修改，并显示“仅依据本次通话转写生成 · 共 6 条原文引用”。

## 5. 与 Sprint 1 验收标准的对应

| Sprint 1 验收项 | 原型体现 |
|---|---|
| 导入中心：拖拽、批量选择、SHA-256 去重、文件类型识别 | 导入中心拖拽区 + 最近导入表 + 右侧设置 |
| 音频/视频处理：ffmpeg 转码、切片、提取音轨 | 处理进度：上传→转码→转写→摘要 |
| ASR 适配层：先 Mock，再切阿里云 Paraformer | 导入设置中的 AI 处理模式：阿里云百炼 / Mock |
| 说话人区分：我 / 客户 | 转写稿中的“客户/我”角色标签 |
| 转写界面：音频播放器、时间戳、点击句子跳转 | 顶部播放器 + 时间戳 + 当前句高亮 |
| 通话摘要：固定七字段 + JSON Schema + 原文引用 | 右侧 AI 摘要七字段 + 引用图标 + 置信度 |
| 空字段处理：预算未提及、时间未提及、下一步未明确 | “付款方式：未提及”示例；其余字段空值文案可复用 |
| 30 分钟录音 10 分钟内出转写+摘要 | 页面状态与处理进度展示目标；实际性能在开发中验证 |
