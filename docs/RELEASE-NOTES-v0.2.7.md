# ClientHub v0.2.7

发布日期：2026-11-01

## 本次更新

- 长音频按约 55 秒切片，最多并发 3 个 Qwen ASR 请求；按原顺序合并，保留片段起止时间。成功片段支持本地缓存、取消和失败重试恢复。
- 新增扫描 PDF、普通图片及多页 TIFF 的离线中英文 OCR，模型随安装包内置。
- 新增 DOC、XLS、PPT、PPTX 正文解析；PPTX 包含表格和备注，旧 PPT 排除历史保存版本和母版占位文本。解析结果继续进入归档、检索、原文预览和备份流程。
- 新增通知中心、未读提醒、到期通知与免打扰设置。到期日 09:00 提醒，默认 22:00–08:00 免打扰；点击通知定位待办，完成、取消或延期后清理旧提醒。
- 优化设置页分区布局，补充导入偏好、数据与备份、本地诊断、更新和通知设置。
- 左上角版本号发现更新时变黄；点击弹窗可查看版本、下载进度、历史更新，下载后重启安装。设置页继续提供相同更新操作。
- 修复安装包中旧版 VC++ 运行库导致 OCR 崩溃的问题，确保 OCR 模型、ONNX Runtime 与 PDFium 原生依赖随包分发。

## 验证与使用说明

- 47 项隔离回归测试、前端构建、Python 编译与 Electron 语法检查通过。
- 已验证浏览器中的通知定位、设置保存，以及图片、扫描 PDF、DOC、PPT 上传闭环；打包后的 Sidecar 也完成这四类文件解析验证。
- 保持单机单用户；普通图片使用“选择文件”或拖放入口，聊天截图使用专用“聊天截图”入口。
- 系统通知依赖 Windows 原生支持；不可用时保留应用内提醒。应用退出后不发送通知，重新启动后补充到期提醒。
- 句子时间为片段内估计值；真实数小时录音的 Qwen ASR 额度与耗时、安装环境下的系统弹窗和更新重启仍需实机验收。
