# ClientHub v0.2.9

发布日期：2026-11-03

## 本次更新

- 新增需求澄清工作台：可从客户和项目入口选择资料，按批次生成带原文证据的问题，并记录回答、历史和手动追问。
- 支持按工作单选择生成语言；支持未归属问题按资料分配，并保留原有问题、回答和来源证据。
- 完善失败、取消、增量重试、冲突处理及需求/项目回写预览；没有模型 Key 或模型调用失败时保留已有数据。
- 可按客户/项目导出对外问题为 Word 或 PDF。PDF 使用 Windows 原生保存对话框，导出内容不包含内部理由、证据、置信度或模型信息。
- 增加客户/项目快捷入口、来源资料跳转与返回、归档/恢复/复制/删除及前 10 次分析指标。
- Sidecar API revision 更新至 17；升级安装不会重置本地 SQLite 业务数据。

## 验证

- 75 项 Python 后端回归和 TypeScript/Vite 生产构建通过。
- 安装版 35 项隔离检查通过，覆盖 9 种资料格式及随包离线 OCR、澄清流程、升级数据保留和卸载。
- 模拟模型调用用于隔离验收；没有执行真实 MaaS 请求。
- 当前包由 GitHub Actions 为 Windows 构建并发布；首次启动后可在设置页配置模型 Key。

## 已知范围

- 全新 Windows 10/11 虚拟机、真实 MaaS 及自动更新下载到重启安装链路未在本轮手动验收。
- 保持单机单用户；此版本没有引入账号、权限或云端协作。
