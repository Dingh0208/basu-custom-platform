# 聊天导入容量与限制（2026-11-03，源码 API21）

## 可用范围

- 单次聊天导入最多 **5,000 条**，微信先按日期与消息类型筛选再计数。第 5,001 条匹配消息触发明确拒绝，不截断、不保存部分聊天；预览只显示“超过 5,000”，不伪报精确总数。
- 本机聊天库累计最多 **100,000 条**，同一会话增量归并，去重后新增消息才占额度。达到上限仍可导入纯重复消息；新增超限整体拒绝，已有聊天和 AI 结果保留。备份后删除不需要的聊天资料可释放额度。
- 5,000 条是原微信读取边界，过去会静默截断；100,000 条沿用主 PRD 9.9 的支持目标，作为本轮明确的产品上限，不代表已测出的物理极限。没有声称支持百万条。
- 聊天详情每页渲染 100 条，搜索覆盖完整聊天；附件索引每页 50 项。详情 API 仍返回全量消息，尚未实现服务端分页，响应大小和客户端内存随总量增长。
- 原有媒体离线复制限制：单附件最多 25 MiB，每次复制累计最多 200 MiB；超过时保留附件索引，不保存该原件。消息数不能替代磁盘大小评估。
- AI 关闭只导入本地原文，显示未分析；只有用户开启自动 AI 或手动点击分析才调用模型。以上容量不承诺 AI 耗时，也没有限制模型输出预算。

## 本机虚构文本实测

独立临时 SQLite，同一会话每批不超过 5,000 条，累计至 100,000 条。每条约 90 个汉字、2 位参与者、唯一消息 ID、无附件、不调用模型。HTTP 列包含完整详情传输和 Python JSON 解码；磁盘列为样本数据库文件大小。

| 1,000 | 0.019 秒 | 0.019 秒 | 0.046 秒 | 0.34 MiB | 0.62 MiB |

## 本轮验证

- 复现空 `analysis={}` 导致详情白屏；修复后虚构未分析聊天、现场 83 条聊天链接及“资料→预览”路径均正常打开，未发送写请求或触发 AI。现场原文未写入测试日志或截图。
- API mock 浏览器验证 AI 关闭的微信完成提示、超限禁用、缩小日期范围恢复、文件/粘贴容量错误原文展示、已分析摘要/问答/需求正常、分页与全量搜索，无页面异常。
- 114 项 Python 回归通过（24.249 秒），TypeScript/Vite 构建和差异检查通过。容量回归覆盖过滤后计数、精确边界、无静默截断、重复不占额度、超限 HTTP 413、历史保留，以及容量失败不留下媒体副本。
- 性能元数据与浏览器验证脚本在被忽略的 `build/`，不包含在正式发布中。正式安装包仍为 v0.3.2/API20，本轮 API21 尚未打包发布。
- 用户执行重启脚本后，实际健康接口为 **0.3.2/API21**，当前 Web 已启用上述限制；AI 导入开关仍关闭，数据目录不变。
