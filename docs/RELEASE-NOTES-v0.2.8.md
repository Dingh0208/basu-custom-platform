# ClientHub v0.2.8

发布日期：2026-11-02

## 本次更新

- 本地诊断增加微信引擎手动启动。启动失败时显示具体原因、日志位置和按错误类型给出的修复步骤；并发启动会合并，避免重复拉起进程。
- 销售待办主面板占满可用工作区；空列表提供直接创建待办的入口。
- 删除客户时关联项目和客户档案会先归档，可从设置逐项目恢复。归档数据纳入数据库备份；恢复遇到同名项目时提示冲突，不覆盖已有项目。
- 旧版 Sidecar 下保护客户删除操作，避免旧接口硬删除关联项目。
- 设置诊断改善旧版 Sidecar 状态识别、启动和失败提示。
- 首页快捷操作改为六个全宽方块入口；导入中心格式说明保持单行，移除固定的录音时长展示。

## 验证

- 销售与归档隔离 SQLite/API 回归测试。
- 微信引擎启动失败修复建议 API 回归测试。
- 前端生产构建、Electron 语法检查及 `git diff --check`。
- GitHub Actions 将执行完整 Windows Sidecar 构建和安装包发布。
