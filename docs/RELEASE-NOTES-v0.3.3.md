# ClientHub v0.3.3

本版优化 Windows 安装包压缩和更新下载量，保留完整功能，并交付此前尚未发布的聊天体验修复。Sidecar API revision 为 21。

## 安装与更新

- 提供两种入口：`ClientHub-Setup-0.3.3.exe` 是完整离线安装包；`ClientHub-Web-Setup-0.3.3.exe` 是小型在线安装器，安装时仍需联网下载完整应用。两者均可选择安装目录。
- Python Sidecar 改为目录式打包，由安装器统一压缩依赖，减少嵌套压缩；后续版本可复用未变化的依赖文件，Sidecar 启动也无需再自解包。Electron、FFmpeg、微信引擎、OCR 模型及文档解析依赖全部保留，安装目录占用会增加。
- 应用内更新继续使用完整 NSIS 包和 blockmap 差分，兼容旧安装器缓存；不因增加在线安装器而切换更新格式。下载安装后仍校验 SHA-512，缓存缺失或差分失败时保留整包下载兜底。
- 设置页版本改为读取应用包版本，修复硬编码旧版本号的问题。

同一环境、源码与压缩参数的本机对比：Sidecar 压缩体积由 108.8 MiB 降至 83.8 MiB，减少约 23%。使用真实 v0.3.2 安装器缓存和 electron-updater 6.3.9，通过本地 HTTP 验证本机构建的 v0.3.3：完整包 343.3 MiB，差分下载 106.8 MiB，少传输约 69%，重建后 SHA-512 一致。这是下载量验证，不是 GitHub 网络测速；公开资产大小以本页 Assets 为准，实际耗时仍取决于网络与缓存。

## 聊天体验修复

- 微信提取完成后准确显示新增/累计消息数；关闭 AI 时不再误报“进入分析队列”。
- 修复未分析聊天的空结果导致详情白屏；保留原文阅读、搜索和手动分析入口。
- 聊天每页显示 100 条、附件每页显示 50 项，搜索覆盖完整记录，降低大量消息与附件的页面渲染负担。
- 微信按日期及消息类型筛选后计数，单次最多 5,000 条；超过时明确提示缩小范围，不再静默截断。
- 本机聊天累计上限 100,000 条，按去重新增量计数；纯重复导入不占额度，超限整体拒绝并保留历史数据。

## 验证与使用

- 114 项 Python 回归与 TypeScript/Vite 生产构建通过。
- 实际冻结运行时验证版本/API21、FFmpeg，以及 DOC、DOCX、XLS、XLSX、PPT、PPTX、EML、图片 OCR、扫描 PDF 九类解析，使用隔离临时数据库与虚构文件，未调用模型服务。
- 发布前检查安装包、在线载荷、更新通道元数据及 SHA-512；资产全部上传后再公开发布。
- 直接安装推荐选择完整离线包；希望先下载小安装入口可选 Web 包。应用内点击更新沿用现有流程，无需手动切换。
- 本版不修改客户资料、模型选择、AI 导入开关或输出长度策略。
