# ClientHub v0.3.4

本版加入 QQ 邮箱邮件勾选导入和多来源统一导入，补充客户项目筛选体验。Sidecar API revision 为 23。

## 邮件与导入

- QQ 邮箱采用手动选择模式。刷新仅读取收件箱邮件列表，不下载正文、不创建资料；未勾选邮件不会进入资料。
- 邮件支持搜索主题/发件人、分页和跨页勾选。选中的邮件加入待导入清单，点击“导入已选”后才下载正文和附件。
- 本地 PDF/其他文件、微信库聊天筛选和已选邮件可以一起加入清单，一次提交；每项可单独勾选或移除。
- 成功项会从待提交选择中移出；失败项可重试，成功内容会保留且不会重复导入。
- 邮件读取仍由用户手动触发，不启用定时同步。清单只在当前页面暂存；尚未提交的选择在刷新页面或离开页面后不会保留。
- 首次读取近 30 天，之后增量发现；每次最多读取 200 封头信息，可继续刷新。每个邮件导入任务最多 100 封、单封上限 25 MB，未选候选会保留供以后选择。

## 客户与项目

- 项目页默认显示全部项目，可按客户姓名或公司搜索并筛选；返回全部项目后恢复全量列表。
- 客户筛选与项目关键词搜索可组合使用；客户暂无项目时显示明确空状态。
- 新建项目会沿用当前筛选客户；在全部项目视图中需明确选择所属客户。

## 验证与使用

- 本机 130 项 Python 回归、TypeScript/Vite 生产构建通过。
- Edge 隔离浏览器验证邮箱默认未选、候选搜索与跨页选择、多来源统一提交、未选项不提交及部分失败重试；全部 API 使用虚构数据模拟。
- Windows 安装包、冻结 Sidecar 与九类本地文档解析由本版 GitHub Actions 发布流程验证。
- 邮箱授权码仅通过设置页在本机录入；保存、测试连接及打开邮件选择均不会自动导入邮件。
- 完整离线安装请选择 `ClientHub-Setup-0.3.4.exe`；`ClientHub-Web-Setup-0.3.4.exe` 是在线安装入口，安装时仍需下载完整应用。应用内更新继续使用 NSIS 完整包和 blockmap 差分。
