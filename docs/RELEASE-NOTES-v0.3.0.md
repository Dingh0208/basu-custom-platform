# ClientHub v0.3.0

发布日期：2026-11-03

## 本次更新

- 新增“资料”模块，集中查看导入记录；可按归档状态、资料类型、客户和项目筛选，并预览原件或解析内容。
- 设置页与导入中心新增共享的“新资料自动 AI 分析”开关。新安装默认关闭；升级时迁移旧的自动识别/自动处理偏好。开关仅影响之后导入的资料。
- 关闭 AI 时，文档、邮件、文本和聊天在本地解析，截图使用离线 OCR；不自动匹配客户或派发 AI 分析任务。音视频先保存原件，在需求澄清中选中并开始分析后才转写。
- 导入时支持手动选择客户和项目；未指定归属的资料进入待归档。
- 扩展本地文本解析，支持 TXT、CSV、JSON 和 HTML。
- Sidecar API revision 更新至 18；同步更新主 PRD 和项目交接状态。

## 验证

- Python 后端回归、TypeScript/Vite 生产构建和 Python 编译通过。
- GitHub Actions 在 Windows runner 构建 Sidecar 和 NSIS 安装包，并发布本版本资产。
- 未调用真实 MaaS 模型；自动 AI 导入默认关闭，避免新安装后导入即产生模型费用。

## 已知范围

- 本版本未完成人工验收的全新 Windows 10/11 安装、覆盖升级和自动更新下载安装链路。
- 保持单机单用户；未引入账号、权限或云端协作。
