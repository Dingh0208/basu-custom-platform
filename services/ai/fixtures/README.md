# Legacy Office regression fixtures

Small sample files from [Apache POI test-data](https://github.com/apache/poi/tree/trunk/test-data), distributed under the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).

- `simple.doc`: `document/simple.doc`; checks Word 97 text extraction.
- `basic_test_ppt_file.ppt`: `slideshow/basic_test_ppt_file.ppt`; includes incremental saves and master text, checks that only current slides and notes are extracted.

These are public test samples, not customer documents.
